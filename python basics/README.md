# Python Learning Journey

This repository is organized as a daily Python learning tracker.

## Learning roadmap

- Day 01: Python Core
- Day 02: OOP
- Day 03: Modules
- Day 04: File I/O
- Day 05: Pytest

## Repository structure

- `source/` contains the active practice exercises from the earlier project
- `notes/` stores daily learning reflections and error logs
- `day_01_python_core/` contains exercises and notes for Python basics
- `day_02_oop/` contains OOP exercises and class-based examples
- `day_03_modules/` contains import and module examples
- `day_04_file_io/` contains file handling examples and practice
- `day_05_pytest/` contains pytest exercises and validation work

## Run the project tests

```bash
pytest
```
